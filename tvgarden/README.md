# TV Garden — channel catalog mirror

Static mirror of the channel catalog used by the **TV Garden** Android app.

| File | What it is |
|---|---|
| `catalog.bin` | The catalog: gzip-compressed JSON, ~284 KB (~1.4 MB uncompressed). |
| `manifest.json` | Version, generation timestamp, SHA-256 and counts, so a client can skip a download that would change nothing and verify the one it does make. |

`catalog.bin` is **gzip bytes**, deliberately not named `.gz` — the Android build unpacks
and renames a `.gz` asset during packaging, which silently breaks the app. Decompress it
yourself; no `Content-Encoding` header is involved.

## Why this mirror exists

The upstream dataset asks downstream users not to depend on `raw.githubusercontent.com`
uptime and warns that its schema may change without notice. This mirror is also where the
expensive work already happened: upstream expresses a channel's category as *membership of
a category file*, so reconstructing it on a phone would mean ~4 MB of near-duplicate JSON
on every refresh. Here it is one file.

Generated by
[`tools/build_catalog.py`](https://github.com/Pandiyarajk/tv_garden) from the upstream
data. Relative to upstream it drops channels with no playable stream, recomputes each
country's channel count over what actually survives, derives a display region, and
normalises ISO 639-2/B language codes onto 639-3.
